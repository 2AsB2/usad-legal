usad-backups

A backup tool by USAD Labs

usad-backups keeps USAD Labs' business systems safe if a computer or server fails. Once a day it makes a backup of each system's database, encrypts it, and copies it to a folder called usad-backups in the owner's own Google Drive.

What it does

  • Creates one folder, usad-backups, in the Google Drive of the account that signs in.
  • Uploads that day's backup files into the folder. Each file is encrypted before it leaves our server, so the contents can't be read in Drive.
  • Deletes its own backup files after 14 days, so only the last two weeks are kept.

What it can't do

It asks Google only for the drive.file permission. With it, the app can see and change only the files it created itself. It can't open, list or change any other file in your Drive.

It is used only by USAD Labs for its own systems. It isn't offered to the public.
